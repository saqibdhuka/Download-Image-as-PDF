# Download Image as PDF

A lightweight, open-source browser extension that lets you right-click any image on a webpage and instantly download it as a PDF document.

Everything happens locally in your browser. No external servers, completely private, and 100% free.

## ✨ Features

* **One-Click Conversion:** Right-click any image to instantly download it as a PDF.
* **Custom Page Sizes:** Click the extension icon in your toolbar to open the settings UI. You can format your PDFs as:
  * **Original Image Size:** Matches the exact dimensions of the image.
  * **A4 (Portrait):** Centers the image on a standard A4 page.
  * **Letter (Portrait):** Centers the image on a standard US Letter page.
* **Master Toggle:** Easily enable or disable the extension's right-click menu directly from the popup UI.
* **Advanced Image Capture (The "Double Fetch" Bypass):** Built with smart fallbacks to capture images even on heavily restricted sites (like Gmail or CORS-protected domains). 
* **100% Private:** Powered entirely by Manifest V3 and the local `jsPDF` library. Your images never leave your computer.

## 🛠️ How to Install and Run Locally (Developer Mode)

Because this extension is not in the Chrome Web Store yet, you can run it locally on your machine using "Developer Mode". This works on Google Chrome, Microsoft Edge, Brave, and other Chromium-based browsers.

### Step 1: Get the Code
1. Click the green **Code** button at the top of this GitHub repository and select **Download ZIP** (Alternatively, grab the latest pre-built `.zip` from the Releases tab).
2. Extract the downloaded ZIP file to an easy-to-find location on your computer (e.g., your Desktop or Documents folder).

### Step 2: Load into your Browser
1. Open your browser and go to the Extensions page:
   - **Chrome / Brave:** Type `chrome://extensions` in the URL bar and press Enter.
   - **Edge:** Type `edge://extensions` in the URL bar and press Enter.
2. In the top right corner of the Extensions page, turn on the toggle switch for **Developer mode**.
3. A new menu bar will appear at the top left. Click the button that says **Load unpacked**.
4. A file browser window will open. Select the folder you extracted in Step 1 (make sure you select the folder that contains the `manifest.json` file).

### Step 3: Use the Extension!
1. Go to any website with an image.
2. Right-click on the image and select **"Download Image as PDF"** from the menu.
3. The image will be converted and a PDF file will instantly drop into your Downloads folder!
*(Tip: Click the extension icon in your browser toolbar to change the PDF page size settings!)*

## 💻 Development

This extension uses vanilla JavaScript and requires no build tools or Node.js setup. 

**Note on Dependencies:** This extension relies on the `jsPDF` library (`jspdf.umd.min.js`). For security reasons under Manifest V3, this file is bundled locally in the repository.

1. Edit the source files directly.
2. Go to `chrome://extensions`.
3. Click the **Refresh** icon on the extension card to reload your changes.

A ready-to-use `.zip` file is automatically generated by GitHub Actions on every push to the `main` branch. You can find it under the **Actions** tab.
